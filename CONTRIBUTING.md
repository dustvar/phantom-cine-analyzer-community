# Contributing

Keep changes focused and documented. Run the headless test suite before opening
a pull request, add regression coverage for behavior changes, and update
`app-source/MODIFICATIONS.playback.txt` when user-visible behavior changes.

Do not commit Cine footage, packaged builds, credentials, signing certificates,
private repository addresses, or customer data. Keep Intensity (Classic)
behavior isolated from opt-in Hybrid changes, and do not modify graph
calculations or styling as part of unrelated UI or tracking work.

All contributions must be compatible with the repository's Non-Commercial Open
Source License.
